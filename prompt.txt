PUBLIC API
==================================================

The syntax must be simple.

Example:

import carvustrain

model = carvustrain.Model(
    name="Carvus"
)

model.train(
    data="train.txt",
    method="normal",
    duration="forever"
)

model.save("carvus.ct")

model.ask("Who are you?")

print(model.answer)
